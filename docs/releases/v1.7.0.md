## MewHub 1.7.0

### 新增：平面直角坐标系

- 在「设置 → 助手 → 工具 → 本地工具」开启「平面直角坐标系显示」。
- 助手可以在回复中直接绘制函数与带标签的坐标点，图表会随聊天记录保存。
- 点击图表的放大按钮，进入全屏坐标工具，修改函数、点位和坐标范围，缩放、平移或重置视图。
- 支持 `x^2`、`2x+1`、`sin(x)`、`sqrt(x)`、`1/x` 等表达式；三角函数使用弧度。
- 使用支持图片的模型时，聊天输入框的「+」中也可以打开坐标工具，将绘制好的图表作为图片加入待发送附件。
- 采用 MewHub 的奶白配色、主题色与圆角样式，适配深色模式。全部图形在设备本地生成，无需外部生图服务。

### Android 兼容修复

- 相册使用 AndroidX 照片选择器，旧系统自动回退至系统文档选择器。
- 补齐打开相册或相机时系统回收进程后的图片恢复，恢复结果放入待发送附件。
- 相机权限被拒绝时，显示清楚的恢复权限提示。
- 统一聊天、设置与裁剪页面的透明系统栏样式，避免旧版 Android 底部重新出现黑色导航区域。

### English

- Added an opt-in, on-device Cartesian plotting tool with functions, labeled points, an editable full-screen view, and PNG chat attachments.
- Improved Android gallery compatibility, recovery after interrupted camera/gallery selection, and camera permission feedback.
- Kept system navigation bars transparent across themes and pages on older Android versions.
