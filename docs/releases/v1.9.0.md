## MewHub 1.9.0

### 二维与三维坐标系，统一一个开关

- 助手设置中的「平面直角坐标系显示」更名为「坐标系显示」，开启后同时提供二维与三维绘图工具。
- 新增空间直角坐标系：支持 `z=f(x,y)` 曲面、三维坐标点与命名点之间的实线/虚线线段。
- 三维曲面由设备本地计算网格、透视投影和深度排序，支持抛物面、马鞍面、球面分支及含三角函数的曲面；未定义区域和超出窗口的部分不会错误连线。
- 聊天卡片和全屏页都支持单指旋转、双指平移与捏合缩放；全屏可编辑标题、曲面、点位及 x/y/z 范围，并提供重置视图。
- 聊天输入框「+」菜单移除坐标系入口，统一由模型调用绘图工具；旧对话中的二维图表继续正常显示。

### MCP 调用更顺畅

- 已启用的 MCP 工具默认直接执行，不再逐次弹出「允许运行这个工具吗」。
- 此默认行为不受助手「运行工具前询问」开关影响；本地剪贴板等需要确认的工具仍保留确认机制。

### English

- One **Coordinate plots** switch enables both 2D Cartesian graphs and the new interactive 3D coordinate system.
- Plot `z=f(x,y)` surfaces, 3D points and segments entirely on-device, with projection and depth-sorted meshes.
- Orbit with one finger and pan/zoom with two in both chat cards and the full-screen editor.
- The composer `+` plotting shortcut is removed; model-generated and existing saved graphs remain available.
- Enabled MCP tools now execute without repeated approval prompts, including when general tool confirmation is enabled. Local tools that explicitly need approval are unchanged.
