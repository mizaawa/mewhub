## MewHub 1.9.3

### 空间坐标系与线段绘制

- 空间坐标系改用正交投影，立方体和其他几何体不再因透视缩放产生额外形变。
- XY 网格根据视口反算平面范围，延伸覆盖整个可见画布，并随缩放保持接近稳定的屏幕密度。
- 平面与空间图均支持实线、虚线、点线、点划线，以及主题色、红、橙、绿、青、蓝、紫、粉、灰、黑等命名颜色。
- 绘图工具提示词说明线段何时使用各线型和颜色；旧图中的 `dashed` 线段仍可正常读取。

### Spatial coordinates and segment styling

- Use orthographic projection so cubes and other shapes are not additionally distorted by perspective scaling.
- Extend the XY grid across the visible canvas by deriving its plane bounds from the viewport, while keeping screen spacing steady as the user zooms.
- Add solid, dashed, dotted and dash-dot segments, plus named theme and palette colors, to both 2D and 3D plots.
- Explain line-pattern and color use in both plot-tool prompts, and continue to read saved segments using the legacy `dashed` field.
