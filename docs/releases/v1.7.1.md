## MewHub 1.7.1

### 主题色完整生效

- 切换主题色（樱花、抹茶、薰衣草、海盐、蜂蜜）后，背景、侧栏、卡片、弹窗、文字、分隔线与阴影会一起换成对应色调，不再停留在焦糖奶白。
- 用户消息气泡、发送按钮、用量卡片和工具卡片的渐变，代码块底色、行内代码文字、顶部提示条和聊天背景的柔光，也都跟随主题色。
- 本对话用量面板中的「输出」颜色始终与主题色区分开。
- 「回复完成」系统通知的图标颜色与当前主题色一致。
- 默认的焦糖主题保持原样；切换主题色时整体配色平滑过渡。

### 助手工具说明

- 「设置 → 助手 → 工具」中的每个开关都有一行简短说明：运行工具前询问、时间日期、计算器、平面直角坐标系显示、剪贴板与设备信息，行高统一。

### English

- Picking an accent now tints the whole interface: surfaces, sidebar, cards, dialogs, text, lines, shadows, gradients, code blocks, toasts, the ambient background and reply notifications. Caramel looks exactly as before.
- Every switch on the assistant Tools tab has a one-line description.
